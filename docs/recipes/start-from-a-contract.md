# Start a service from an OpenAPI contract

The document is the source of truth: it generates the types, it is enforced on
every request, and the handlers are written against both. Edit `openapi.yaml`
first, run `go generate ./api/...`, then make the compiler happy.

```yaml path=api/openapi.yaml
openapi: 3.1.0
info: {title: Shop API, version: 1.0.0}
servers:
  - url: /api/v1
paths:
  /invoices:
    post:
      operationId: createInvoice
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              required: [customer, amountCents]
              unevaluatedProperties: false
              properties:
                customer: {type: string, minLength: 1}
                amountCents: {type: integer, minimum: 1}
      responses:
        "201":
          description: created
          content:
            application/json:
              schema: {$ref: '#/components/schemas/Invoice'}
    get:
      operationId: listInvoices
      parameters:
        - {name: limit, in: query, schema: {type: integer, minimum: 1, maximum: 100}}
      responses:
        "200": {description: ok}
  /invoices/{id}:
    get:
      operationId: getInvoice
      parameters:
        - {name: id, in: path, required: true, schema: {type: string}}
      responses:
        "200":
          description: ok
          content:
            application/json:
              schema: {$ref: '#/components/schemas/Invoice'}
components:
  schemas:
    Invoice:
      type: object
      required: [id, customer, amountCents]
      properties:
        id: {type: string}
        customer: {type: string}
        amountCents: {type: integer}
```

```go path=api/api.go
// Package api embeds the contract and holds the types generated from it.
package api

import _ "embed"

//go:generate go run github.com/oapi-codegen/oapi-codegen/v2/cmd/oapi-codegen@v2.8.0 -generate types -package api -o api.gen.go openapi.yaml

// Spec is the OpenAPI document: the source of truth for this service's API.
// Edit it first, then regenerate.
//
//go:embed openapi.yaml
var Spec []byte
```

`-generate types` and nothing else. The `std-http-server` target would also emit
`HandlerFromMux`, and the service would then have two ways to register a route;
handlers stay plain `http.HandlerFunc` on the app's mux. Pin the generator
version: `@latest` makes the output depend on the day it ran.

What the command produces, for reference — never edit it:

```go path=api/api.gen.go
// Package api provides primitives to interact with the openapi HTTP API.
//
// Code generated by github.com/oapi-codegen/oapi-codegen/v2 version v2.8.0 DO NOT EDIT.
package api

// Invoice defines model for Invoice.
type Invoice struct {
	AmountCents int    `json:"amountCents"`
	Customer    string `json:"customer"`
	Id          string `json:"id"`
}

// ListInvoicesParams defines parameters for ListInvoices.
type ListInvoicesParams struct {
	Limit *int `form:"limit,omitempty" json:"limit,omitempty"`
}

// CreateInvoiceJSONBody defines parameters for CreateInvoice.
type CreateInvoiceJSONBody struct {
	AmountCents int    `json:"amountCents"`
	Customer    string `json:"customer"`
}

// CreateInvoiceJSONRequestBody defines body for CreateInvoice for application/json ContentType.
type CreateInvoiceJSONRequestBody CreateInvoiceJSONBody
```

```go path=internal/invoices/handler.go
// Package invoices implements the contract's invoice operations.
package invoices

import (
	"net/http"
	"strconv"

	"github.com/guilhermebr/gox"

	"example.com/shop/api"
)

type handler struct{}

// Register mounts the contract's operations. Every pattern repeats the
// /api/v1 prefix the document declares under servers: the mux decides what
// exists, and a pattern that does not match what the document describes is a
// 404 before validation ever runs.
func Register(a *gox.App) {
	h := &handler{}
	a.HandleFunc("POST /api/v1/invoices", h.createInvoice)
	a.HandleFunc("GET /api/v1/invoices", h.listInvoices)
	a.HandleFunc("GET /api/v1/invoices/{id}", h.getInvoice)
}

// createInvoice takes the body type generated from the contract. The body is
// already valid: openapi.Enable rejected anything the document forbids, so
// Decode only fails on malformed JSON.
func (h *handler) createInvoice(w http.ResponseWriter, r *http.Request) {
	var in api.CreateInvoiceJSONRequestBody
	if err := gox.Decode(r, &in); err != nil {
		gox.Error(w, r, err)
		return
	}
	_ = gox.JSON(w, http.StatusCreated, api.Invoice{
		Id:          "inv_1",
		Customer:    in.Customer,
		AmountCents: in.AmountCents,
	})
}

// listInvoices shows the one gap in types-only generation: the contract's
// query parameters become api.ListInvoicesParams, but nothing fills it in.
// Read them yourself; they have already been validated.
func (h *handler) listInvoices(w http.ResponseWriter, r *http.Request) {
	var params api.ListInvoicesParams
	if raw := r.URL.Query().Get("limit"); raw != "" {
		n, err := strconv.Atoi(raw)
		if err != nil {
			gox.Error(w, r, gox.InvalidArgument("limit must be a number").WithDetail("field", "limit"))
			return
		}
		params.Limit = &n
	}
	limit := 20
	if params.Limit != nil {
		limit = *params.Limit
	}
	_ = gox.JSON(w, http.StatusOK, make([]api.Invoice, 0, limit))
}

// getInvoice reads the path parameter from the mux, not from a generated
// type: path parameters produce no struct.
func (h *handler) getInvoice(w http.ResponseWriter, r *http.Request) {
	id := r.PathValue("id")
	if id != "inv_1" {
		gox.Error(w, r, gox.NotFound("invoice %s", id))
		return
	}
	_ = gox.JSON(w, http.StatusOK, api.Invoice{Id: id, Customer: "acme", AmountCents: 1000})
}
```

```go path=main.go
package main

import (
	"os"

	"github.com/guilhermebr/gox"
	"github.com/guilhermebr/gox/openapi"

	"example.com/shop/api"
	"example.com/shop/internal/invoices"
)

func main() {
	// openapi.Enable goes last. An authenticating option passed before it
	// answers anonymous callers with a 401 rather than a description of the
	// contract.
	a := gox.MustNew("shop", gox.HTTP(), openapi.Enable(api.Spec))

	invoices.Register(a)

	if err := a.Run(); err != nil {
		os.Exit(1)
	}
}
```

## The mistake to avoid

A `servers` entry with a path — `url: /api/v1` — is part of every route the
document describes. `openapi.Enable` resolves requests against the document
including that prefix, so a handler registered on `POST /invoices` while the
contract describes `/api/v1/invoices` is never validated **and** never reached:
the mux answers 404 first, and the contract looks like it is being ignored.
Register `POST /api/v1/invoices`. Routes the document does not describe, such
as `/healthz` or a webhook, pass through untouched and need no entry.

## Keeping it in step

- Change the contract, run `go generate ./api/...`, and the build breaks
  wherever a handler no longer matches. That is the point.
- Adding an operation is two edits: the document, then a `a.HandleFunc` line
  and a method in the tag's package.
- Validate responses in tests, not in production traffic.
- `gox.WithErrorRenderer(gox.ProblemJSON)` when the contract declares problem
  details for errors — see `problem-json-errors.md`.

A generator that emits its own router and handler signature, such as ogen, buys
compile-time routing at the cost of a second router, a second error model and a
second middleware API inside one binary. Types-only keeps the contract on the
payloads, where the drift actually happens, and leaves `net/http` alone.
