# gox — build a Go service with one import

gox is an opinionated service framework. It chooses the logger, config loader, HTTP server, middleware, observability, health endpoints and lifecycle so you do not. A plain HTTP service imports only `github.com/guilhermebr/gox`. Heavy integrations are opted in by importing their package and passing `Enable()` to `gox.New`: `gox/postgres`, `gox/jobs`, `gox/jwt`, `gox/openapi`, `gox/web`, and third-party clients under `gox/providers/*` (`gox/providers/mailgun`, `gox/providers/posthog`, `gox/providers/s3`, `gox/providers/stripe`, `gox/providers/supabase`, `gox/providers/temporal`, `gox/providers/workos`).

This file, llm.txt, is a single-file export: `gox docs` generates it from `docs/llm/*.md` and the doc comments of the modules below. Order: mains, layout and testing; `## API:` (signatures, first doc sentence) and `## Config:` (variables) sections per module; conventions, ending with the Never list. With a shell, read only what the task needs, from sources that match the version in your go.mod: `go doc github.com/guilhermebr/gox.Periodic` (any package or symbol, full doc comments), `go run ./cmd/<name> --help` (every variable the service reads), and the recipe index `docs/recipes/README.md` in the directory `go list -m -f '{{.Dir}}' github.com/guilhermebr/gox` prints (empty until `go mod download github.com/guilhermebr/gox`).

Rules that always hold:
- `main()` is `gox.MustNew(name, options...)`, handler registration, then `a.Run()`. gox owns start order, config, health, shutdown.
- Handlers are plain `net/http`: `func(w http.ResponseWriter, r *http.Request)`, registered with Go 1.22 patterns (`"GET /invoices/{id}"`, `r.PathValue("id")`). `"GET /{$}"` is the exact root; `"GET /"` is a catch-all.
- Config comes from environment variables under one prefix, the uppercased service name: service `billing` reads `BILLING_HTTP_ADDR`, `BILLING_POSTGRES_URL`. `gox.WithConfigPrefix("")` makes them unprefixed. `--help` prints every variable.
- Errors: return `gox.NotFound("invoice %s", id)` style errors and render them with `gox.Error(w, r, err)`: the JSON envelope, or the error page for browser requests once `gox/web` is enabled (`web.Error` is the same call). Never write status codes by hand for errors.
- Accessors for undeclared features panic with a message naming the option to add; read the message and add the option.
- Every service gets, without writing code for it: structured logs with request ids, Prometheus metrics, traces once OTEL export is on (production, `<PREFIX>_OTEL_ENDPOINT` or `<PREFIX>_OTEL_ENABLED=true`), `/healthz` and `/readyz` on the public port, an admin server on `:9090` with `/metrics`, `/healthz`, `/readyz`, `/version`, `/debug/pprof/`, graceful shutdown on SIGTERM.

Install: `go get github.com/guilhermebr/gox` (root) and `go get github.com/guilhermebr/gox/<module>` per feature (`postgres`, `providers/s3`, ...); HTML apps: see the templ notes with the server-rendered main below. Go 1.26+.
